# MIA Orders — Λήψη εφαρμογής 0.2

Το ZIP περιέχει την εφαρμογή για τοπικές δοκιμές, με το πραγματικό μενού (123 εγγραφές, 215 τιμές), προσωπικό κωδικό, ιστορικό και backups.

## Λήψη

1. Άνοιξε το αρχείο **MIA-Orders-0.2.0-testing.zip** σε αυτόν τον φάκελο.
2. Πάτησε **Download raw file** (το εικονίδιο λήψης). Αν ζητηθεί, συνδέσου στον GitHub λογαριασμό σου.
3. Αποσυμπίεσε ολόκληρο το ZIP σε νέο φάκελο του υπολογιστή σου.
4. Με εγκατεστημένη Python 3.12+, άνοιξε το **START_MIA_ORDERS.bat** στα Windows. Σε Linux/macOS: `python3 START_MIA_ORDERS.py`.
5. Στην πρώτη εκκίνηση χρειάζεται Internet για εξαρτήσεις και θα ορίσεις προσωπικό κωδικό. Όνομα χρήστη: **admin**.

Οι παραγγελίες είναι δοκιμαστικές, χωρίς χρεώσεις ή δημόσια online λειτουργία. Το πακέτο δεν περιλαμβάνει κωδικούς, βάσεις πελατών ή δεδομένα της τοπικής εγκατάστασης.

Πέρασαν 120 δοκιμές και η πλήρης ροή σε Chromium από το αποσυμπιεσμένο πακέτο. Η πραγματική εκτέλεση του batch σε Windows χρειάζεται δοκιμή στον δικό σου υπολογιστή.

Η εγκατάσταση ανοίγει τοπικά τον χώρο προσωπικού. Το **START_HERE.txt** μέσα στο ZIP περιλαμβάνει τις αναλυτικές οδηγίες.
