# MIA Orders — Διορθωμένη έκδοση 0.2.1

## Κατέβασε το νέο αρχείο

Άνοιξε το **MIA-Orders-0.2.1-testing.zip** στον φάκελο downloads και πάτησε **Download raw file**. Συνδέσου στο GitHub αν ζητηθεί. Το παλιό 0.2.0 παραμένει μόνο για ιστορικό.

## Τι διορθώθηκε

Το μήνυμα **Port 8000 is already occupied** δεν σταματά πλέον την κανονική εκκίνηση. Αν η 8000 χρησιμοποιείται από άλλο πρόγραμμα, το MIA επιλέγει αυτόματα διαθέσιμη θύρα και ανοίγει τη σωστή διεύθυνση στον browser. Δεν κλείνει ξένες υπηρεσίες. Θυμάται τη θύρα της ίδιας εγκατάστασης για επόμενο διπλό κλικ.

## Πώς ανοίγει

1. Κράτησε τον παλιό φάκελο της εφαρμογής και τα δεδομένα του.
2. Αποσυμπίεσε ολόκληρο το νέο ZIP. Για αναβάθμιση στον ίδιο φάκελο, αντικατέστησε μόνο αρχεία προγράμματος και διατήρησε **runtime**, **.venv** και **backups**.
3. Άνοιξε το **START_MIA_ORDERS.bat** με εγκατεστημένη **Python 3.12+**. Η εκκίνηση γράφει **MIA Orders 0.2.1-testing**.
4. Στην πρώτη εκκίνηση χρειάζεται Internet για εξαρτήσεις και προσωπικός κωδικός. Χρήστης **admin**.

Το πακέτο περιλαμβάνει το πραγματικό μενού 123 εγγραφών / 215 τιμών και τις διορθώσεις σου. Παραμένει έκδοση τοπικών δοκιμών, χωρίς χρεώσεις ή δημόσια online λειτουργία. Δεν περιλαμβάνει προσωπικούς κωδικούς, βάσεις, δεδομένα runtime ή backups.

Η διόρθωση ελέγχεται με πραγματικό σενάριο κατειλημμένης θύρας, σύνδεση προσωπικού και παραγγελία. Οι ιδιαιτερότητες άρνησης bind στα Windows καλύπτονται επιπλέον με δοκιμές. Η πραγματική εκτέλεση σε Windows πρέπει να επιβεβαιωθεί στον δικό σου υπολογιστή.
